# 🧠 Jogo da Memória

Um aplicativo Android simples e divertido do clássico jogo da memória.

## 🎯 Objetivo

O objetivo do jogo é encontrar todos os pares de cartas correspondentes exercitando a memória e a concentração.

## 🚀 Como Jogar (Regras)

1. Ao iniciar a partida, você verá um conjunto de cartas viradas para baixo (a quantidade varia conforme a dificuldade escolhida).
2. Toque em duas cartas para revelá-las.
3. Se as imagens reveladas forem iguais, você encontrou um par e elas permanecerão visíveis.
4. Se as imagens forem diferentes, as cartas irão virar para baixo novamente após 1 segundo. Tente memorizar a posição delas!
5. O jogo termina quando você encontrar todos os pares.

## 🏆 Pontuação

Ao final da partida, o seu desempenho é avaliado e uma pontuação é calculada com base no tempo gasto e na quantidade de movimentos realizados (tentativas). Quanto mais rápido e com menos erros você terminar, maior será a sua pontuação final!

A fórmula exata utilizada para o cálculo é:
`Pontuação = 100.000 / (Movimentos × Tempo em Segundos)`

*Dica: Sua maior pontuação (High Score) fica salva no seu dispositivo para você tentar bater seu próprio recorde!*
